# Portfolio publishing and privacy policy

This public repository is a **professional portfolio**, not a source-code mirror of private products.

## Publicly shareable

- Professional background and technology areas
- High-level, non-confidential descriptions of project problems and engineering approaches
- Carefully verified milestones already approved for public discussion

## Not for publication

- Source code, screenshots, designs, or documentation copied from private repositories without an explicit disclosure decision
- API keys, environment variables, credentials, database records, or customer information
- Internal infrastructure hostnames, network diagrams, security controls, or deployment topology
- Proprietary detection logic, business relationships, financial details, and unannounced plans
- Claims of certifications, live integrations, commercial launch, or completed testing that have not been verified

## Review before changes

Before expanding a public project description, verify that each claim is factually accurate, does not reveal restricted information, and clearly separates research, development, validation, and production.

**Privacy is the default.** Public portfolio changes do not require changing any product repository visibility or granting repository access.
